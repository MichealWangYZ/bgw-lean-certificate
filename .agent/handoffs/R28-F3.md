## Key theorems

* `Lowdin.lowdin`: for `R : Matrix m n ℝ` with `frob2 (R Rᵀ - 1) < 1`, there is `S` with
  `S Sᵀ = 1` and `frob2 (S - R) ≤ frob2 (R Rᵀ - 1)`.
  * `S = U diag(λ^{-1/2}) Uᵀ R`, built from `Matrix.IsHermitian.spectral_theorem`.
  * Exactly, `frob2(S - R) = Σ(1 - √λ)²`; the bound uses `sqrt_defect_le`.

* `Lowdin.exists_completion_nat`: orthonormal `k` rows in `ℝ^L` have `k ≤ L` and a
  completion by exactly `L - k` rows (`Orthonormal.exists_orthonormalBasis_extension_of_card_eq`).

  `RowDist P (dL)`, where `dL t = √η_t`.
* `exists_compl`: for any energies `ε` there is a `cp` with `K t = L - N_b` and

## The δ bound and the propagation term

* **δ.** `δ_t = √η_t`, with `η_t = ‖R Rᵀ - 1‖_F²` of the stored rows (`gramDef`). The bound
  is `‖R* - R‖_F² ≤ η_t`; in fact it is about `η_t/4` for small `η`. Every row is within
  `δ_t`.
* **Propagation.** `radP - radK₁ + cenErr + compErrA` on Σ(E_o). On the step it is
  `radP - radK₁ + cenErr + 2·compErrA`, with the ψ kernels.
* **Definitions.** `e(G) = √(Σ_v A_v(G)²)·δ_t`, and `prodErr(x, y, e_x, e_y) = e_x|y| + |x|e_y + e_x e_y`.
  * `dT_ij = Σ_{n<N_b} prodErr(M_n(G_i), M_n(G_j), e_i, e_j)`.
  * `radP` inflates `T_ii` to `T_ii + dT_ii` in Cor's radius.
  * `cenErr = Σ|v_i| dT_ij |c_ji|`.
  * `compErrA = Σ_t [Σ_{n<nocc} Σ_g |v^x_g|(2 e_g|M_ng| + e_g²) + Σ_ij |v_i| 751|IeU_ji| dT_ij]`.

## Remaining trust (also in the Lean module docstring and in the docs)

* **Eigenvectors.** The rows `P` are not proved to be the EPM eigenvectors. The Löwdin
  rows are exact eigenvectors of the surrogate `H*`. For the EPM eigenvectors the
  theorems need only `RowDist P d` (named hypothesis). The computable quantity is
  Davis-Kahan, `d ≤ ‖H Rᵀ - Rᵀ diag E‖_F / gap(N_b, N_b+1)`, which needs `H`. It is not
  formalised and not evaluated.
* **State `a` and omitted energies.** State `a` stays the stored row. Omitted energies
  enter only via `x ≤ -D`, as in Cor.
* **Not covered.** F4 (static remainder, `κ - 1` residual) is not addressed here. With
  `κ = 1` the `(κ - 1)I/4` obstruction of F4 is absent for `CompleteP`, but no theorem here
  states it.
