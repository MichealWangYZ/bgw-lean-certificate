## 2. Contract implemented

Definitions (`GW/GPP/PoleCancellation.lean`, namespace `GW.GPP`), all over `ℝ`:

```text
rawOccupied A x w  = -A / (x ^ 2 - w ^ 2) + A / (2 * w * (x - w))
occupiedTerm A x w = A / (2 * w * (x + w))
emptyTerm A x w    = A / (2 * w * (x - w))
```

### S1 theorems

| Requirement | Name | Statement / hypotheses |
| --- | --- | --- |
| algebraic cancellation | `GW.GPP.rawOccupied_eq_occupiedTerm` | `(A x w : ℝ) (hw : w ≠ 0) (hp : x ≠ w) (hm : x ≠ -w) : rawOccupied A x w = occupiedTerm A x w` — exactly the S1 hypotheses, arbitrary real `A` (either sign) |
| generic version | `GW.GPP.raw_eq_occupied_field` | same identity in any `[Field K] [CharZero K]`, hypotheses `w ≠ 0`, `x - w ≠ 0`, `x + w ≠ 0` |
| extension value | `GW.GPP.occupiedTerm_at_pole` | `(A w : ℝ) (_hw : w ≠ 0) : occupiedTerm A w w = A / (4 * w ^ 2)` (the `w ≠ 0` hypothesis is kept for spec fidelity; the identity is definitional in Lean, hence the `_` prefix to silence the unused-variable linter) |
| continuity | `GW.GPP.continuousAt_occupiedTerm` | `(A w : ℝ) (hw : w ≠ 0) : ContinuousAt (fun x => occupiedTerm A x w) w` |
| punctured limit | `GW.GPP.tendsto_rawOccupied_nhdsWithin_ne` | `(A w : ℝ) (hw : w ≠ 0) : Tendsto (fun x => rawOccupied A x w) (𝓝[≠] w) (𝓝 (A / (4 * w ^ 2)))` |

The limit is a genuine filter limit along the punctured neighbourhood `𝓝[≠] w`,
not an evaluation of the merged formula at a point. It is proved from
`GW.GPP.rawOccupied_eventuallyEq_occupiedTerm`, which says the raw and merged
expressions agree eventually on `𝓝[≠] w`; the extra exclusion of `-w` is free
because `GW.GPP.pole_ne_pole` gives `w ≠ -w` from `w ≠ 0`, so `{-w}ᶜ` is already
a neighbourhood of `w`. `GW.GPP.empty_denom_zero_at_pole` records that the empty
branch genuinely has a vanishing denominator at `x = w` (no cancellation there).

### S2: data, real model, evaluator (`GW/GPP/FiniteSelfEnergy.lean`)

* `Term` = `coefficient, omega, epsilon : ℚ`, `occupied : Bool`;
  `Data` = `sigmaX : ℚ`, `terms : List Term` (multiplicity retained).
* `Term.offset t E = E - t.epsilon` (`x`); `Term.denom t E = 2*w*(x+w)` if
  occupied else `2*w*(x-w)` — computed with no division.
* Unchecked helpers (named `*Unchecked`, documented as relying on Lean's
  totalized division `a / 0 = 0`): `Term.valueUnchecked`, `Data.sigmaUnchecked`.
* Real model: `Term.valueReal` (selects `occupiedTerm` / `emptyTerm` on cast
  data) and `Data.sigmaReal` (`(sigmaX : ℝ) + list sum`).
* Checked public entry points: `Term.check` and `Data.sigmaChecked`, returning
  `Except EvalError ℚ` with `EvalError.nonpositiveOmega` / `.zeroDenominator`.
  Both validity tests run **before** any division and are independent of the
  coefficient, so `A = 0` does not rescue invalid data.

| Requirement | Name | Statement |
| --- | --- | --- |
| rational-to-real term | `GW.GPP.Term.valueUnchecked_cast` | `((t.valueUnchecked E : ℚ) : ℝ) = t.valueReal (E : ℝ)` |
| rational-to-real finite sum | `GW.GPP.Data.sigmaUnchecked_cast` | `((D.sigmaUnchecked E : ℚ) : ℝ) = D.sigmaReal (E : ℝ)` |
| checked evaluation soundness | `GW.GPP.Data.sigmaChecked_ok_eq_real` | `D.sigmaChecked E = .ok s → (s : ℝ) = D.sigmaReal (E : ℝ)` |
| domain validity | `GW.GPP.Data.sigmaChecked_ok_valid` | `D.sigmaChecked E = .ok s → ∀ t ∈ D.terms, 0 < t.omega ∧ t.denom E ≠ 0` |

Supporting: `Term.denom_cast`, `list_sum_valueUnchecked_cast`,
`Term.check_ok_omega_pos`, `Term.check_ok_denom_ne_zero`, `Term.check_ok_eq`,
`checkedValues_ok_valid`, `checkedValues_ok_eq`,
`Data.sigmaChecked_ok_eq_unchecked`, `Data.sigmaChecked_nil` (empty list returns
`sigmaX`), and `Term.check_occupied_at_pole` (an occupied term with `w > 0` and
`x = w` is **accepted** and returns `A / (4 * w ^ 2)` — the intended continuous
extension, per S2).

### Failed attempts worth recording

* `decide` cannot prove any of the fixture facts on this toolchain: kernel
  reduction gets stuck on `Rat.mul` / `Rat.inv` / `Rat.sub` (e.g. `example :
  (2:ℚ)/3 = 2/3 := by decide` fails, and `(1:ℚ)/3 + 1/6 = 1/2` is not `rfl`).

  equations. `native_decide` was never used and must not be introduced as a fix.

  rejection facts are proved by `norm_num` on `Term.check`, not by `decide`.
* `import Mathlib.Tactic.Push.Cast` and `import Mathlib.Tactic.NormCast` do not
  exist in this mathlib revision; `push_cast` is available transitively and the
  imports were dropped.
* `simp` closes goals of the form `t.denom E = 4 * t.omega ^ 2` into a residual
  `¬ t.omega = 0` side goal; `Term.check_occupied_at_pole` uses explicit
  `rw [if_neg …, if_neg …]` instead.

## 6. Remaining gaps, assumptions, trust boundaries

* **Physics correspondence is not proved.** The scalar restriction, the
  identification of `A`, `w`, `x`, and the SX/CH split are the documented
  interpretation in `docs/SOURCE_MAP.md`. No BerkeleyGW source checkout,
  revision, or exported data was available; nothing here verifies BerkeleyGW,
  derives GW from diagrams, or certifies a material.
* **Units are an input contract**, not a type-level theorem (eV for `E`, `eps`,
  `w`, `sigmaX`, `Sigma`; eV^3 for `A`). Nothing in Lean enforces this.
* **Kernel vs. runtime.** The proofs are kernel-checked elaborated terms. The
  Lean compiler, the runtime, console IO, the Python oracle, and the exactness
  of any external measurement are separate trust boundaries. The successful
  `gpp_demo` run does not verify the compiler or runtime, and the oracle
  agreement is a test, not a proof.
* **No floating-point claim.** The binary64 comparison lives only in the
  supervisor's `scripts/reference.py` and is labelled an experiment there; the
  Lean side contains no float statement and no energy tolerance.
* **Totalized division.** `Term.valueUnchecked` / `Data.sigmaUnchecked` are
  documented as non-physical when a denominator vanishes; only
  `Data.sigmaChecked` may be read as a model value.
* **Fixture facts are samples**, not theorems about arbitrary inputs. This is
  stated in the header of `GW/Examples.lean`.
* **Proposed specification changes: none.** S1-S5 were implemented as written;
  no hypothesis was strengthened, no branch removed, no coefficient sign
  restricted, and the fixture is unchanged.
* Minor deviation worth a reviewer's eye: `occupiedTerm_at_pole` takes `w ≠ 0`
  as `_hw` because the equation holds definitionally in Lean; the statement is
  still the S1 statement (a weaker-hypothesis theorem would also be sound here,
  but I did not change the contract).
