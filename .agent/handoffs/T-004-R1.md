## 2. The six findings

### F1 -- the headline allowed cross-output cancellation

Confirmed. `totals["signed"]` accumulated signed values across all 53 outputs
before dividing, so different `mtxel_cor` calls, matrix elements, q-points and
`iw` energies cancelled against one another -- contradicting the module's own
grouping rule, which exists precisely to stop that.

| Aggregate | Value |
| --- | --- |
| per-output magnitude first (**new primary**) | **`0.010558548317668193` = 1.0559%** |
| cross-output signed (old headline, now diagnostic) | `0.006730753905587463` |

Cross-output cancellation destroyed **36%** of the magnitude. The old figure is
retained in the JSON as `cross_output_signed_over_accumulators` with a
`cross_output_warning` naming it a diagnostic and saying "Do not quote it as
the size of the effect", because it was previously published. The 49.6%
per-group result is unaffected.

### F2 -- units and missing factors

Confirmed, both parts.

*Units.* `ssx` and `sch` are dimensionless, but the weight carries
`vcoul(igp)`, which BerkeleyGW holds in Rydberg, so these sums and
`asxtemp`/`achtemp` are **intermediate Rydberg** values. "Dimensionless" was
wrong.

*Outer factors.* They are now listed per output type, because they genuinely
differ: diagonal elements take `neq` at `sigma_main.f90:1586-1587` and then
`ryd/ndeg` at `shiftenergy.f90:113`, while offdiagonal elements take
`ryd*neq` at `sigma_main.f90:1860-1861` and no degeneracy average at all --
the subspaces are built at `shiftenergy.f90:69` by a loop over `sig%ndiag`
only. So `1/ndeg` is **not** universally missing.

### F3 -- a definite reporting bug

Confirmed exactly. I reused the variable `rel` for the reconstruction residual
after computing `signed_over_local` into it, so every group emitted the
residual instead of the ratio. Call 107 reported `8.083277010591748e-16`; the
true value is `2524.158843794141`. Renamed to `recon_rel`; a test now asserts
the emitted value equals `|signed| / |local|` recomputed from the same group.

### F4 -- the COHSEX comparison was incomplete

Confirmed. `sigma_cohsex` guards **both** its CH accumulation sites with
`if (sig%exact_ch==0)`, and the witness runs `exact_static_ch 1`. Under the
witness configuration `sigma_cohsex` contributes no CH channel, so a
two-channel comparison against it is undefined.

I **withdrew** the comparison rather than conditioning it. Conditioning would
leave a claim about a configuration no run in this project uses, which is the
kind of untested statement that produced the last three findings. The sentinel
limit `(occ - 1/2)*ieps` is unaffected and retained; the open question in the
review packet now asks what the right reference for that limit is, instead of
asserting a sign relation.

### F5 -- accumulator identity exported but unchecked

Confirmed; your band-999 demonstration reproduced. The parser kept only
`(asxtemp, achtemp, subtotal)` and discarded the row's own band, spin,
calculation type and q-point. It now compares them against the identity the
group's records claim and rejects a mismatch:

```
group (107, 2): accumulator identity (1, 999, 8, 1, 0.0, 0.0, 0.5) does not
match the identity its records claim (1, 8, 8, 1, 0.0, 0.0, 0.5)
```

### F6 -- committed provenance incomplete

Confirmed, and **larger than reported**. You found 4 files (16/18 and 23/25).
Checking all four manifests rather than two, there were **9**: the five extra
are vouched by `PROVENANCE.txt` and `PROVENANCE-R1.txt`
(`artifacts/t003/check_occupation.json`, `artifacts/t003/fermi_sigma_hp.log`,
and three under `artifacts/t003-r1/`). All nine are now tracked, 193 kB total.

The real fix is `tests/test_provenance_committed.py`, so it cannot regress. It
asserts every repo-relative path vouched by any manifest is tracked, and that
the **current** manifests match the files as they stand. It deliberately does
**not** assert that on historical manifests -- those must disagree, since
T-003-R1 item 6 required recording repaired digests as a new revision rather
than rewriting history. A fourth test guards that guard by asserting at least
one historical digest is stale, so the exemption cannot silently become vacuous.
