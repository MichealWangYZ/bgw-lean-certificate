## 2. The six repairs

### 1. Units and missing factors, at the module contract

The JSON had been corrected in R1 but the **module surface had not**: the
docstring still said "internal (dimensionless) units", "not an energy", and
listed `1/ndeg` as universally missing. Rewritten as an explicit table:
`K*L` carries **intermediate Rydberg energy units**; `1/ndeg` is missing for
**diagonal outputs only** (`shiftenergy.f90:113`, subspaces built at `:69` over
`sig%ndiag`); `ryd` enters at a **different later location** per output type
(`shiftenergy.f90:113` for diagonal, `sigma_main.f90:1860-1861` for
offdiagonal). It remains not a final self-energy, physical energy error,
observable or eV result -- but it is no longer called dimensionless or "not an
energy".

New `ModuleContractTests` (4 tests) assert this against `wm.UNITS`,
`wm.MISSING_FACTORS`, `wm.COMPLETENESS_EVIDENCE` and `wm.__doc__` directly, so
the contract is covered independently of emitted JSON. The packet's "not an
energy" wording was removed for the same reason.

### 2. Finite sentinel

The clamp sentence was truncated mid-phrase ("The clamp predicate is / Codex's
exact evaluation:") by my R3-era edit. Repaired, and it now states both
conjuncts explicitly: `|ssx| ~ 0.25` is not `> sexcut*|ieps| = 1`, and
`wxt = 10 > 0`, so neither holds.

The report no longer presents the finite value as equal to its limit. Added,
exactly:

```text
x = 1      ->  -125000000000/1000000000001  = -0.124999999999875
x = 10     ->  -12500000000/100000000001    = -0.12499999999875
x = 100    ->  -1250000000/10000000001      = -0.1249999999875
x = 1000   ->  -125000000/1000000001        = -0.124999999875
```

It varies by `1.1e-11` between `x = 10` and `x = 100`, approaches `-1/8` only
as `w -> infinity`, and never attains it. "Static" is now explicitly shorthand
for the limit. Two regression tests
(`test_finite_sentinel_is_not_its_limit_and_depends_on_x`,
`test_sentinel_clamp_predicate_needs_both_conjuncts`) pin the exact fractions,
the strict inequality against the limit, and the `x` dependence. No COHSEX
comparison was restored.

### 3. 1.056% as a chosen dataset L1 norm

Removed the claims that cross-group cancellation "has no physical meaning" and
that the L1 aggregate is the "PRIMARY"/"defensible" one. The corrected framing,
in both the analyser strings and the packet: taking magnitudes per
`(call_id, iw)` is a **choice** that avoids cancellation *within this
diagnostic*; that is a property of the choice, not evidence that such
cancellation is unphysical, since BerkeleyGW deliberately sums related q-point
and call contributions with their outer factors on the way to a self-energy.
**Neither** the L1 norm nor the signed cross-group ratio is a physical error
estimate; the 36% gap measures internal cancellation of this dataset, not which
number is right. The value `0.010558548317668193` and its pre-outer-factor
qualification are unchanged. 49.6% is now described as a **per-call
accumulator-group** result everywhere, not "single output".

### 4. What the tally check proves

tally**, and no more. Completeness additionally requires two documentary links,
now emitted as `completeness_evidence` and stated in the packet:

   place (`t4_b == 2 .and. t4_o == 2`), readable in the patch;
2. **same-run provenance** -- one execution of one binary wrote both files.

`relationship` no longer says "COMPLETE ... whole population"; it says what is
checked and names what is not. `cardinality_matches_tally` is a separate
boolean. The `76462/3701` mutation test is preserved and the count gate is
unchanged.
