## Required Work

### A. Pole Cancellation

Define the raw split occupied term, merged occupied term, and empty term over
the reals. Prove the cancellation for arbitrary real `A, x, w` under exactly
the nonzero hypotheses in S1. Generic field algebra is fine if convenient, but
the real corollary must be explicit. Use denominator factorization and existing
field tactics. Do not specialize the result to the synthetic fixture.

Prove the value and continuity of the merged expression at `x=w`. Prove a true
punctured limit of the raw expression as `x` approaches `w`. Relate it to the
merged expression on a punctured neighborhood that also excludes `-w`; note
that `w != 0` separates the two points. A proof just evaluating the merged
formula at one point is insufficient for the limit requirement.

### B. Exact Finite Evaluator

Use rational inputs and binary occupancy. Define a real-valued mathematical
model and an executable rational evaluator. One suitable representation is a
structure of rational term parameters plus a list of terms and static constant.
Prove cast preservation through the branch and finite sum. The implementation
and mathematical definition should make the finite computation inspectable.

Add a checked entry point, using `Option` or `Except`, that rejects nonpositive
`w` and zero selected denominators BEFORE division. Reject invalid terms even
when their coefficient is zero. Prove that success implies both domain validity
and equality of the cast result with the real model. Keep unchecked helpers
clearly named and document Lean's totalized division.

### C. Examples and CLI

Use exactly the three-term fixture in S3. Produce a runnable `gpp_demo` which
prints per-term values, the total `-11/6`, and rejection cases. Provide a
`--json` mode with the following stable schema for the supervisor's oracle:

```json
{"fixture":"synthetic-three-term-v1","terms":["2/3","-1","-1"],"sigma":"-11/6","occupied_at_pole":"1","reject_zero_omega":true,"reject_negative_omega":true,"reject_occupied_pole":true,"reject_empty_pole":true,"empty_sum":"-1/2"}
```

Here `occupied_at_pole` uses `A=4,x=1,w=1`. Format rationals canonically: an
integer has no `/1`; a fraction has numerator/denominator without spaces.
For unknown command-line flags return nonzero with a usage message. Compute
values and rejection booleans from actual evaluator calls, never hardcode the
expected results into output. Fixtures in Lean may be constants and must have
proofs (`norm_num`, `decide`, or simplification, never `native_decide`).

The allowed foundational axioms are `propext`, `Classical.choice`, `Quot.sound`.
