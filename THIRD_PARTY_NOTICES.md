## What is redistributed, and in what form

### Verbatim BerkeleyGW files

Copied unmodified from `testsuite/Si-EPM/` in the archive:

* `bgw/export/WFN.in`
* `bgw/export/WFNq.in`
* `bgw/export/WFN_co.in`
* `bgw/export/epsilon.inp`
* `bgw/export/sig_GPP.inp`

`bgw/occupation_audit/fixtures/fermi_sigma.inp` and
`bgw/weighted_audit/fixtures/fermi_sigma.inp` derive from
`testsuite/Si-EPM/sig_GPP.inp`; they append two or three input keywords,
which are marked with a comment in the file.

### Build configuration derived from a BerkeleyGW template

`bgw/export/arch.mk` is the build configuration used for the BerkeleyGW build
described in `docs/BERKELEYGW_4.0_GPP.md` section 7. It has the same variable
set as `config/generic.serial.linux.mk` in the archive, from which it was
derived; the values (compiler paths, `-DUSEFFTW3`, library paths) were
replaced. It is byte-identical to the `arch.mk` placed in the build tree.

### Diffs against BerkeleyGW source

`bgw/occupation_audit/t003_instrument.patch` and
`bgw/weighted_audit/t004_instrument.patch` are unified diffs against
`Sigma/mtxel_cor.f90` (SHA-256
`8914dc00ac8d80d99e78f9b76a6d398491240bf147fa8714a65fed4ce5daf1dd`).
As unified diffs they contain unmodified context lines from that file.
They add only counters, local variables and `write` statements; no
expression, branch condition or accumulation is altered.

### Quoted source

`docs/BERKELEYGW_4.0_GPP.md`, `bgw/occupation_audit/REPORT.md`,
`bgw/weighted_audit/REVIEW_PACKET.md` and comments in
`GW/GPP/BerkeleyGWMap.lean`, `bgw/kernel_transcript.f90` and the Python
checkers quote short excerpts of BerkeleyGW Fortran for identification and
commentary, each with file and line references.

### Output and derived data

`bgw/export/sigma_hp.log`, `bgw/*/fixtures/*.dat` and files under
`artifacts/` are output of, or measurements taken from, an execution of
BerkeleyGW 4.0 on the Si empirical-pseudopotential test case shipped with
the archive. Benchmark reference values quoted from
`testsuite/Si-EPM/Si.test` are BerkeleyGW's own regression targets.

## Scope of claims

This repository makes no claim that BerkeleyGW is correct or incorrect, and
none about the accuracy of the GW approximation. Where it reports a
discrepancy between a comment and the code, or between two branches of one
kernel, that is a statement about source text and algebra, not a defect
report. See `bgw/weighted_audit/REVIEW_PACKET.md` sections 1 and 5.
