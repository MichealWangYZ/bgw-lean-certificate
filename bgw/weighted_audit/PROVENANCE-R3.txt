asserts they are tracked AND absent from the current manifest.

  K*L carries intermediate Rydberg energy units, not dimensionless;
  1/ndeg missing for diagonal outputs only; ryd enters at a different
  later location per output type. Covered by ModuleContractTests, which
  test the module surface rather than emitted JSON.
2 REPORT.md: broken clamp sentence repaired; the finite w=1e12 value is
  shown to be x-dependent and only to approach (occ-1/2)*ieps as
  w -> infinity, never attaining it. Exact-rational regression added.
3 1.056% is stated as a CHOSEN dataset L1 norm, not a preferred physical
  effect size; claims that inter-call/inter-q cancellation is physically
  meaningless are removed; 49.6% is a per-call accumulator-group result.
4 the tally check is described as proving cardinality and id
  sequentiality; completeness is stated as additionally requiring the
  shared-predicate and same-run-provenance links, emitted as
  completeness_evidence. The 76462/3701 mutation test is preserved and
  the count gate is unchanged.
5 the packet no longer hard-codes a status; the correction table is 23
  rows with mixed attribution, two entries self-reported; the evidence
  index names R4, this manifest, the acceptance record and all handoffs.
