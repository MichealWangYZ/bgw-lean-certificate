The numbers in BerkeleyGW's binary files WFN, WFNq, WFN_inner and RHO are read by bgwio.py and written into Lean as exact dyadic rationals (every float64 is a dyadic, and the exporter asserts the conversion is exact). Lean does not parse the files.

Why it matters. If the reader mis-parses a record, every theorem downstream is about the wrong numbers.

1 · Symmetry unfolding Kernel-checked in Lean

From the irreducible k-points and the crystal's 48 operations (integer matrices, fractional translations t = t2/2), Lean rebuilds every wavefunction on the full grids, the G-spheres, BerkeleyGW's sphere order and the ε index map, and checks them equal to what the later stages consume. It also checks the 32-point k-set is the group closure and the weights.

Why it matters. Unfolding (rotations, the non-symmorphic phase of diamond, the last-match op choice) was the largest piece of trusted Python before; a sign error here changes χ and Σ.

    def rotate(self, ik, iop, kg0):
        """Coefficients of O psi_{k_ik}, re-expressed at k' = M k + kg0.

        (O psi)(x) = psi(g^{-1} x) with g: x -> W x + t. For psi = sum_G c(G)

2 · Dielectric matrix ε Kernel-checked in Lean

ε_GG'(q) = δ_GG' − v(q+G)·χ(G,G'), with χ = 4/(N_k Ω) Σ_{k,v,c} M_vc(G) M_vc(G')/(E_v(k+q) − E_c(k)) and v = 8π/|q+G|² (real π). The kernel proves the TRUE ε, computed from the unfolded coefficients, lies in the interval box the inverse step uses, at all 3 q-points.

Why it matters. This is the RPA screening every later number depends on.

    Gs, _ = spec.sphere_of(er.cr, er.gvec, q, ecut)
    n, nv = len(Gs), 4
    chi = I.exact(np.zeros((n, n)))
    for k in er.kfull:

        src = er.wfq if q0 else er.wf

def cover(qp, lo, hi, min_width=1e-9, max_boxes=2_000_000, split_width=1e-6, roots=None):
    """Cover [lo, hi] by intervals on which f certainly has no zero. Returns
    (number of boxes, smallest width used, number of branch-split boxes) or
    raises if it cannot."""
    stack, n, wmin, nsplit = [(lo, hi)], 0, np.inf, 0
    while stack:
        a, b = stack.pop()
        # boxes may contain the finitely many points where the source divides
        # by zero (wx = -w; IEEE NaN, not a root under any convention): there
        # the enclosure uses the clamp value 0, the limit from both sides
        F = f_safe(qp, I(a, b))
        ok = F is not None and not F.contains_zero()
        if not ok and b - a < split_width and split_excludes_zero(qp, I(a, b)):
            ok, nsplit = True, nsplit + 1
        if ok:
            n += 1
            wmin = min(wmin, b - a)
            if n > max_boxes:
                raise RuntimeError("too many boxes")
            continue
        if b - a < min_width:
            r = isolate_root(qp, 0.5 * (a + b)) if roots is not None else None
            if r is None:
                raise RuntimeError(f"cannot exclude a root in [{a!r}, {b!r}]: f = {F}")
            roots.append(r)
            ra, rb = r["bracket"]
            # the bracket is certified; cover what is left of [a, b] and of the
            # pending boxes that overlap it
            pending = [(x, y) for x, y in stack]
            stack = []
            for x, y in pending + [(a, b)]:
                if x < ra:
                    stack.append((x, min(y, ra)))
                if y > rb:
                    stack.append((max(x, rb), y))
            continue
        c = 0.5 * (a + b)
        stack.append((c, b))
        stack.append((a, c))
    return n, wmin, nsplit

def isolate_root(qp, c, halves=(1e-4, 3e-5, 1e-5, 3e-6, 1e-6, 3e-7, 1e-7), steps=40):
    """Certify exactly one root of f near c. On a bracket B = [c-h, c+h]: every
    branch condition decided (f continuous), f'(B) excludes 0 (f strictly
    monotone), and f(c-h), f(c+h) have certainly opposite signs (IVT). Then
    bisect the root enclosure. Returns dict or None."""
    for h in halves:
        a, b = c - h, c + h
        before = _undecided()
        undef0 = cert.STATS.get("source_undefined_possible", 0)
        try:
            qp.f(I(a, b), strict=True)
            # every branch decided, and no point of B where the source's
            # formula divides by zero (so the claim needs no NaN convention)
            if _undecided() != before or cert.STATS.get("source_undefined_possible", 0) != undef0:
                continue
            fp = dsigma(qp, I(a, b)) - I.exact(1.0)
            fa, fb = qp.f(I.exact(a)), qp.f(I.exact(b))
        except (Undecided, ZeroDivisionError, NotImplementedError, FloatingPointError):
            continue
        if fp.contains_zero():
            continue
        sa = 1 if fa.lo > 0 else (-1 if fa.hi < 0 else 0)
        sb = 1 if fb.lo > 0 else (-1 if fb.hi < 0 else 0)
        if sa == 0 or sb == 0 or sa == sb:
            continue
        lo, hi = a, b
        for _ in range(steps):
            m = 0.5 * (lo + hi)
            fm = qp.f(I.exact(m))
            if (fm.lo > 0 and sa > 0) or (fm.hi < 0 and sa < 0):
                lo = m
            elif (fm.lo > 0 and sb > 0) or (fm.hi < 0 and sb < 0):
                hi = m
            else:
                break
        return dict(bracket=[a, b], root=[lo, hi], fprime=[float(fp.lo), float(fp.hi)],
                    sign_left=sa)
    return None

10 · GW vs exact (finite models) Kernel-checked in Lean

For any finite fermion system H0 + λV with real two-body integrals, H0 diagonal in the reference orbitals and a strict Slater-determinant ground state: the true Σ(ω; λ) = λ·HF + λ²(direct + SOX + relax) + O(λ³) (|remainder| ≤ K|λ|³ for some K and small |λ|, ω off the unperturbed excitations), while at ω also off the GW poles (GWOffPoles) G0W0 gives λ·HF + λ²·direct; elsewhere sigmaGW2 is a totalized polynomial. So GW misses SOX and relax at second order (relax = 0 under the Brillouin condition). Hubbard dimer: Σ_exact = U/2 + direct + SOX exactly, for every U.

Why it matters. The model layer: what GW leaves out, as theorems rather than estimates. It does not bound GW for real silicon.
