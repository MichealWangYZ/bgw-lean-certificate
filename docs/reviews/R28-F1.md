## The finding

`sigA_eps_eq_theory_q0` (`GW/Bridge/EpsQ0Sigma.lean`) takes three inputs independently:
* the screening blocks `bs : ℕ → EpsBlock κ`;
* the run data `gl`;
* the state data `st`.

No hypothesis says that the screening system's orbitals, energies, occupations, density,
geometry and interaction are the ones in Σ. The theorem stays true if you keep `bs` and
change the energies in `st`, so it cannot identify one physical system. That theorem is
unchanged. This task adds `GW/Bridge/Common.lean`.

## What is now proved (Lean, `GW/Bridge/Common.lean`)

The axioms of every theorem below are `propext`, `Classical.choice` and `Quot.sound`.

* **The common system.** `MF` is the data record of a finite mean-field system: closed
  shell, spin unpolarised, real flavour. It has:
  * a Born-von Karman grid of `NK` k-points;
  * the cell (`B` = bdot, `Om` = celvol);
  * at every grid point, the G-sphere `G k`, the coefficient rows `c k` of all `nb` bands,
    and their energies `e k`;
  * `nocc`, the number of occupied bands;
  * the density list `rho`.

  It is a data record only. Nothing requires the coefficient rows to be orthonormal, and
  there is no Hamiltonian or eigen-equation: `Compat` identifies the screening and Σ
  inputs as images of the same data, not as eigenstates of one `H`.

  The plans `EP` (one per screening block) and `SP` (Σ) contain index data only:
  * `k + q`, `-k` and `k0 - q_t` as grid indices;
  * the eps sphere;
  * Σ's q-list with its symmetry map;
  * the multiplet.

  The plans contain no orbitals, energies, occupations or cell.
* **The two maps.**
  * `MF.inp` / `MF.blk` give EpsSpec's `Input`, summed over the WHOLE grid with ALL bands.
    They also give the theory Bloch system `MF.sp`, built from the same orbitals, with
    momentum-conserving pair densities and `V = N_k Ω`.
  * `MF.gl` / `MF.st` give SigmaSpec's `Gl` and `St`. These hold all bands at every
    `k0 - q_t`.
* **`MF.blk_ok`.** For the system's own blocks, four of the five non-geometric
  `EpsBlock.OK` hypotheses become theorems:
  * `vol`, `volpos`;
  * `res` (the unfolding trust `ResOK`);
  * `tr` (`TROK`, only from the time-reversal property `MF.TR` of the system's data);
  * `bands` (complete bands and momentum conservation).

  `ResOK` and `Bands` hold by construction: the theory pair density `MF.sp` builds
  momentum conservation in through the index map `plus` of the trusted plan, not from
  Bloch structure.

  The proof needs:
  * well-formedness `MF.WF`;
  * a consistent grid plan `EP.WF` (`plus` and `neg` map the grid into itself, `neg` is
    an involution, and `-(k+q)+q = -k`);
  * `MF.TR`.

  Only `qne` (`q + G ≠ 0` on the sphere) stays a hypothesis.

  **Where `MF.TR` can hold.** `MF.TR` is an exact, ordered list identity: no sphere
  permutation, no umklapp vector, no sign or multiplet rotation. `MF.tr_fixed`: at a grid
  point that `neg` maps to itself (a time-reversal-invariant point such as Γ, X or L, when
  `neg` encodes `-k`), it forces every sphere vector to be `0`.
  `compat_selfpaired_no_TR`: if `k0` is self-paired under a block's `neg` and its sphere
  holds a nonzero vector, that block cannot satisfy `MF.TR`. `Z` is a `Finset`, so `hT`
  covers infinitely many blocks. Consequences:
  * for O1 (X and L are time-reversal-invariant) the hypotheses of `sigA_compat` are
    unsatisfiable when every plan's `neg` encodes `-k` on a grid that stores each k-point class once, which fixes X and L
    (trusted plan semantics, not a theorem: `MF` has no k-coordinates), whose spheres hold a nonzero vector (`hyps_unsat_of_selfpaired`), or, for arbitrary plans, given `hnp` (no grid index
    stores the negated sphere list of X or L), which `bgw/r28_f1/check.py` checks on the
    Si-EPM Σ grid (`hyps_unsat_of_unpaired`): the common-system theorem cannot be applied
    to O1 at all. (Storing X/L once does not give `hnp`: a finite cutoff sphere does not
    determine k. Corrected in R28-R3.);
  * with every plan's `neg` encoding `-k` on a grid that stores each k-point class once
    (trusted plan semantics, not a theorem), `MF.TR` also fails on every Γ-centred grid, BerkeleyGW's standard
    ε setup.

  A `TR` with a sphere permutation, an umklapp vector and an orthogonal rotation within
  degenerate multiplets at self-paired points (`TROK` only needs products `M·M`) would
  remove this; it is open, not formalized.
* **`sigA_common` (the composed theorem).** Take SigmaSpec's `SigA` of the system's Σ data,
  with `eps⁻¹` the inverse of EpsSpec's eps of the same system's blocks. It equals the
  theory `SigT` plus `COR`. `SigT` is built from the inverse theory RPA eps `1 - vχ0` of
  the same system's orbitals. Both inverses are Mathlib's totalized `Matrix.inv` (`0` for
  a singular matrix); they are genuine inverses when `det eps ≠ 0`, which is not
  established for these blocks. The blocks in `Z` are the exception: there `eps⁻¹ = E0` is
  an INPUT on both sides (`Espec` and `Etheory` both use `E0` on `Z`), so the `q = 0`
  head and wings are not derived in the composed theorem (see below). The remaining named
  hypotheses are:
  * `qne`;
  * `hC` (`vb = vc`). It is met trivially by `vc := vb`, and the theory side then uses
    the mini-BZ averages. The physical case `vc = vBareK` (point values) fails on the run;
    `sigA_compat` does not identify the Σ and ε interactions (`coulomb_same` states that
    link but is not a premise);
  * `hWq` (the `q ≠ 0` wing factors are 1);
  * `hZ` (`ZeroAt` at `q = 0`);
  * `hX` (`|x| ≥ TOL_Zero`). It fails structurally for Σ(E_o) of every standard
    calculation: at `q = 0` and `iw = 0`, `x = 0` exactly for `n1 = a` and its
    degenerate partners, and every BerkeleyGW Σ q-list contains `q = 0`. The spec
    replaces `x` by `TOL_Zero` there; `wxS_close` bounds `|Δx| < 2·TOL_Zero`, but no Lean
    theorem propagates that to Σ. The identity covers the `iw = 1` (E_o + dE) evaluation
    where the other hypotheses hold;
  * `ModeOK` off the `q = 0` wings.

  `Espec_q0_input` only says that BerkeleyGW's `q0` block can be that input: with `E0`
  EpsSpec's `q0` block, the spec side is EpsSpec's eps on every block, which is what
  BerkeleyGW computes. BRIDGE-Q0 is the separate `q0` analysis.
* **`Compat` (the compatibility predicate) and `sigA_compat`.** `Compat S EPs Z P bs gl st`
  holds when:
  * `(bs iq).inp = S.inp (EPs iq)` for every `iq ∉ Z`;
  * `gl = S.gl P`;
  * `st = S.st P`;
  * `k0` and every `k0 - q_t` are grid points (fields `k0`, `minus`, added in R28-R2).

  For any such data, `sigA_compat` states: `SigA gl (Espec Z E0 bs) … st = SigT(S) + COR(S)`.
  The right-hand side is built from the system and the trusted plans, with the Coulomb
  function `vc` free (see `hC`), not from `bs`. `compat_self` shows the predicate can be
  satisfied when the Σ states are grid states.

  Before R28-R2 the predicate lacked `k0` and `minus`. The Σ states could then sit at an
  index outside the grid, which no screening block reads, and REVIEW-28 F1's adversarial
  case (same screening, arbitrary Σ energies) satisfied the predicate. `offgrid_loophole`
  is that construction as a kernel-checked theorem, kept as the record.
* **The predicate rules out unrelated data.**
  * `inp_pins`: one grid `q ≠ 0` block determines the grid size, and the sphere, all
    coefficient rows and all energies at every grid point.
  * `compat_st_unique`: given `bs`, at most one `st` is compatible, whichever system is
    used.
  * `compat_energy_shift` is the reviewer's adversarial case. Keep `bs` and `gl`, and shift
    the Σ state energies (`Ek ↦ Ek + 1`). Then no system `S'` satisfies `Compat`.

  `compat_st_unique` and `compat_energy_shift` need one block `iq ∉ Z` whose `plus` maps
  the grid onto itself. Grid membership of `k0` and every `k0 - q_t` is now part of
  `Compat`, so they no longer take separate `hk0`/`hmin` premises.
* **The interaction and the density.**
  * `coulomb_same`: EpsSpec's `v(q+G) = 8π/|q+G|²` for the system's block equals `vBareK`
    of the system's Σ data at the key `2(q+G)`. This needs the two encodings of `q` to
    agree, and then both sides use the same bare Coulomb interaction of the one cell.
  * `MF.DensOK`: the density list is the system's own occupied density
    `ρ(g) = (2/N_k) Σ_k Σ_{n<nocc} Σ_{G_i-G_j=g} c c`. Under it, `omT_dens` states that
    the HL `Ω²` of `SigT` uses the same system's density.

  `DensOK` is a named hypothesis and is not discharged.

**Not in Lean (trusted, as in SigmaSpec):**
* that the plans' index maps encode the k-coordinates (`k+q`, `-k`, `k0-q_t`);
* Σ's sphere symmetry map (`idx`, `neg`, `iq`; `Screening.mapping`).

**The `q = 0` block is an input by necessity.** A finite BvK system has no `q = 0` RPA
block, because `v(0)` is singular. BerkeleyGW computes the `q0` block at the finite
`q0 = (0, 0, 0.001)`, with valence states at `k + q0` taken from WFNq. Those states are
auxiliary states, not grid states (`bgw/r28_f1/data/check.json`, `F2_q0_partners`). The
distance between that block and the `q → 0` limit is the subject of BRIDGE-Q0.

**Result.** Screening and Σ are computed for **two different finite systems** of what
appears to be the same EPM Hamiltonian (F3 row):
* the shifted 32-point k-set, with BvK volume 32Ω;
* the unshifted 8-point grid, with `N_q = 8`.

So no system satisfies `Compat` with these data and any screening block derived
(`iq ∉ Z`). A block outside `Z` pins the system's grid states to the Epsilon states
(`inp_pins`), while `Compat.k0` and `Compat.minus` require the Σ states to be grid states,
and the two k-sets share no point. (This holds for the predicate as corrected in R28-R2;
before it, the off-grid construction of `offgrid_loophole` met the predicate.)
`sigA_compat` therefore does not apply to the run as one system. The theorem that does
apply, `sigA_eps_eq_theory_q0`, relates these two systems as independent inputs. This is
the reviewer's interface gap, now measured.

The size of the k-sampling mismatch on O1 was not measured. Recomputing eps on the Σ grid
would give one grid, but it would not make `sigA_compat` usable as formalized: all 8
points of the unshifted Σ grid are time-reversal-invariant, so `MF.TR` fails there
(`MF.tr_fixed`; `check.json` `F2_ksets.sigma_ks`: every coordinate is 0 or ½). A
generalized `TR` would be needed first; it is open.

> `eps⁻¹` the inverse of EpsSpec's eps off `Z`) equals the G0W0 / HL-GPP theory `Σ`
> built from the same `S` and the trusted plans, plus the static remainder `COR`. Here
> `S` supplies its coefficient rows, energies, occupations, cell and density, and the
