## Note after PR #30 (2026-10-05)

Codex's independent re-review of PR #29 (finding 3) showed that the round-3 argument
from "a grid that stores X/L once" to `hnp` is invalid: a finite cutoff sphere does not
determine k modulo the reciprocal lattice, and `MF` carries no k-coordinates, so storing
a point once does not exclude another index holding its negated sphere list. PR #30
withdrew the argument in `hyps_unsat_of_unpaired`'s docstring. The replacement premises
(R28-R3) are:
- with the plans' `neg` encoding `-k` on a grid that stores each k-point class once (trusted
  plan semantics, not a theorem: `MF` has no k-coordinates), X and L are fixed in every
  block; their spheres hold a nonzero vector, and `hyps_unsat_of_selfpaired` makes the hypotheses of `sigA_compat` unsatisfiable without
  `hnp`;
- for arbitrary plans, `hyps_unsat_of_unpaired` with `hnp`, which `bgw/r28_f1/check.py`
  (`hnp`) checks numerically on the Si-EPM Σ grid; for X and L no grid point stores the
  negated sphere even as a set, so the check holds for any sphere ordering.

The conclusion (the common-system theorem cannot be applied to O1) is unchanged; its
stated premise was wrong. The records above are kept, with pointers to this note.
