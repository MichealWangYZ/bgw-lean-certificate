\begin{frame}{The test case: a deliberately fragile observable}
\begin{columns}[T]
\begin{column}{0.52\textwidth}
\small
\begin{itemize}
\item BerkeleyGW 4.0, \texttt{testsuite/Si-EPM}, shipped inputs, pristine binaries (archive sha256-pinned),
      real flavour, serial.
\item EPM mean field, $V_{xc}=0$: $E^{\rm QP} = E^{\rm EPM} + \Sigma$. Model silicon, not real silicon.
\item $O_1$: conduction-band ordering $X$ vs.\ $L$ (each a multiplet average).
\item In mean field $X$ is 0.628\,eV \emph{below} $L$; G$_0$W$_0$ reverses it to $+15.4$\,meV.

      and CH ($+0.5$--$0.6$\,eV).
\end{itemize}
\end{column}
\begin{column}{0.44\textwidth}
\small
\begin{block}{Why this one}
A quantity that looks stable while its parts are not. At the 1.5\,Ry cutoff used in an early
milestone, the same run gives $O_1=-75.4$\,meV: the sign flips with a single control.
\end{block}

\begin{frame}[fragile]{The statement}
\begin{lstlisting}[language=lean]
theorem o1_enclosure_irr_unconditional :
    O1 glI stXI stLI EIrr vbTrue oqTrue ∈
      Icc ((8880811588953599 : ℝ) / 2 ^ 59) ((8880812351936001 : ℝ) / 2 ^ 59)
\end{lstlisting}
\small
\begin{itemize}
\item \texttt{O1} is a real number defined by the Lean specification: $\chi^0$ from pair densities with
      exact energy denominators, $\varepsilon = 1 - v\chi^0$ with $v = 8\pi/|q{+}G|^2$ and real $\pi$,
      the true $\varepsilon^{-1}$, GPP modes, X/SX/CH, the static remainder, the linearised QP equation.
\item Inputs are the \emph{irreducible} WFN/WFNq/WFN\_inner coefficients; the unfolding to the full grid
      (k-closure, sphere order, $\varepsilon$ index maps) is proved, not assumed.
\item \texttt{vbTrue}, \texttt{oqTrue}: the exact mini-BZ averages $\frac{1}{|\Omega_q|}\int 8\pi/|q{+}G{+}p|^2\,dp$,
      Lebesgue integrals over the cell; 1363 + 7 boxes proved.
\item Checked by the Lean kernel with \texttt{decide +kernel}; the audit admits only
      \texttt{propext}, \texttt{Classical.choice}, \texttt{Quot.sound}. No \texttt{sorry}, no \texttt{native\_decide}.
\end{itemize}
\end{frame}

\begin{frame}{What the 5.21\,$\mu$eV is}
\small
\begin{itemize}
\item Production evaluates $\bar v(q{+}G)$ by Monte Carlo (MT19937, seed 5000). The averages differ
      from the integrals by up to $1.7\times10^{-3}$ (relative) and break star symmetry.
\item Individual $E^{\rm QP}$ differ from the specification by $\approx 0.14$--$0.18$\,meV
      (CH by $\approx 0.14$--$0.30$\,meV). In $O_1$ these cancel to 5.21\,$\mu$eV.
\item With production's \emph{own} Monte Carlo averages, the interval evaluator (Python, outward
      binary64) encloses the printed $E^{\rm QP}$ of all four states and $O_1$.
\item The 5.21\,$\mu$eV is an exact-rational comparison of the printed value with the kernel-checked
      endpoints (1\,neV print-rounding allowance).
\end{itemize}
\vspace{2mm}
\begin{alertblock}{Reading}
On this deck, BerkeleyGW 4.0 computes exactly what its source says, to within its Monte Carlo
quadrature. No implementation discrepancy was found on any active code path.
\end{alertblock}
\end{frame}

\begin{frame}{The $q\to0$ cell: one direction of an anisotropic $\varepsilon^{-1}$}
\small
\begin{itemize}
\item $\Sigma$ carries $\varepsilon^{-1}$ to the full $q$-grid by the space-group formula and, for each $q$,
      uses the \emph{last} matching (iq, op) pair. For $q=0$ that is op 48 of 48.
\item The head and wings at $q_0=(0,0,0.001)$ are direction-dependent, so this choice selects one
      direction:
      \begin{itemize}
      \item over all directions BerkeleyGW could have picked, $O_1 \in [14.34, 15.41]$\,meV;
      \item the direction average (cubic crystal) gives 14.89\,meV;
      \item exactly degenerate states split: the $\Gamma$ valence SX$-$X spreads by 36\,meV
            before the multiplet average hides it.
      \end{itemize}
\item Other facts that surfaced: the $\varepsilon$ $k$-sum runs over the 32-point symmetry closure of the
      shifted $2{\times}2{\times}2$ grid, not the nominal 8; wings at $q\neq0$ are rescaled through the
      \emph{irreducible} $G=0$ and the sortrx-first $v$.
\end{itemize}
\vspace{1mm}
\scriptsize\textcolor{pyiv}{These numbers are outward-interval (Python) results, not kernel-checked.}
\end{frame}

\begin{frame}{From theory to the specification: conditional identities}
\footnotesize
\begin{itemize}
\item Proved in Lean, under named hypotheses: the pole signs of $\Sigma$ from the damped Fourier transform
      of time-ordered $G_0$; the HL-GPP kernel algebra and SX/CH split; the static $\chi^0$/RPA
      structure (the factor 4 = spin $\times$ two time orderings).
\item Every place where the code departs from the theory is named in a departure table: wings at $q=0$,
      Coulomb averaging, mode-drop thresholds, \dots, each ``proved equal'' or ``named approximation''.
\item What formalization exposed:
  \begin{itemize}
  \item at $q=0$, $i\omega=0$ the argument $x$ is exactly $0$ for the state itself; the code substitutes
        \texttt{TOL\_Zero}, so the identity covers $\Sigma(E_o+dE)$ but not $\Sigma(E_o)$;
  \item the GPP kernel is discontinuous at $(x,\Omega^2)=(0,0)$: modes dropped because rounding
        makes $|\Omega^2|$ tiny are exactly right only in the ideal metric;
  \item the one-system theorem cannot be instantiated at $X$ or $L$ (time-reversal-invariant
        points; a formal obstruction, \texttt{hyps\_unsat\_of\_selfpaired}).
  \end{itemize}
\end{itemize}
\vspace{1mm}
\scriptsize These identities are \emph{not} instantiated on the certified run. They are not a derivation
of the GPP f-sum prescription.
\end{frame}

\begin{frame}{What is not claimed}
\begin{columns}[T]
\begin{column}{0.5\textwidth}
\begin{block}{Trusted, not proved}
\small
\begin{itemize}
\item decoding and export of the run files into Lean literals;
\item that the Fortran evaluates the specification (source reading on every active path);
\item the production execution itself.
\end{itemize}
\end{block}
\end{column}
\begin{column}{0.46\textwidth}
\begin{alertblock}{Not claimed}
\small
\begin{itemize}
\item that BerkeleyGW is correct on any other input;
\item that 18 bands are converged;
\item that GW/GPP or the EPM describe silicon;
\item formal verification of BerkeleyGW's physics.
\end{itemize}
\end{alertblock}
\end{column}
\end{columns}
\vspace{3mm}
\small Trusted computing base: the Lean 4.19 kernel (with GMP \texttt{Nat}), Mathlib, the elan installer.
No external re-checker (lean4checker) has been run yet.
\end{frame}
